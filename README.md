# 小飞猪的书签 (Bookmark Tree)

**小飞猪的书签** 是一款美观实用的 Chrome 浏览器扩展，它能将您的新标签页替换为清晰的树状书签视图，帮助您更高效地管理和访问收藏的网页。

## ✨ 功能特点

*   **树状视图管理**：以清晰的树形结构展示书签，支持展开/折叠文件夹，层级关系一目了然。
*   **新标签页替换**：完美替代默认的新标签页，让您的书签触手可及。
*   **搜索功能**：支持快速搜索书签，按下回车键即可访问。
*   **个性化定制**：
    *   **背景设置**：支持自定义背景图片或使用纯色/渐变背景。
    *   **主题切换**：内置多种深色模式主题（如 Deep Blue, Midnight Purple）及高颜值渐变配色。
*   **便捷交互**：
    *   **拖拽排序**：支持通过拖拽轻松调整书签顺序。
    *   **右键菜单**：提供新建、编辑、删除等常用操作。
    *   **多种打开方式**：支持在当前标签、新标签或弹窗中打开链接。

## 🚀 安装方式

### 方式一：Chrome 应用商店安装 (推荐)

直接访问 Chrome 应用商店进行安装，享受自动更新：
> [点击此处前往 Chrome 应用商店](#) (链接待补充)

### 方式二：离线/开发者模式安装

如果您下载了源代码或离线安装包（.zip 文件），请按照以下步骤安装：

1.  下载并解压本项目代码（如果是压缩包）。
2.  在 Chrome 浏览器地址栏输入 `chrome://extensions` 并回车。
3.  开启右上角的 **"开发者模式" (Developer mode)** 开关。
4.  点击左上角的 **"加载已解压的扩展程序" (Load unpacked)** 按钮。
5.  在弹出的文件选择窗口中，选择本项目解压后的文件夹（包含 `manifest.json` 的目录）。
6.  安装完成！现在打开新标签页即可看到效果。
