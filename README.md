# 小飞猪的书签 v4.0.0

**小飞猪的书签** 是一款用于 Chrome 新标签页的书签管理扩展。它将书签目录、搜索、常用 AI 站点和个性化主题整合到一个高密度但可读的新标签页工作台中。

## 功能特点

- **双布局模式**：支持树状模式和平铺模式。树状模式适合层级浏览，平铺模式采用左侧目录、右侧卡片列表的分屏布局。
- **平铺分屏体验**：平铺模式将时间、搜索框、目录和书签卡片重新对齐，减少无效边框和容器感，让目录更像轻量导航。
- **智能卡片尺寸**：未手动设置尺寸的平铺卡片会按书签 ID 稳定分配默认尺寸，避免列表全部是标准卡片；用户自定义尺寸始终优先。
- **卡片比例优化**：平铺卡片支持多种尺寸，`1*2` 卡片按正方形比例渲染，卡片间距、圆角、图标和标题显示经过重新调校。
- **即时主题切换**：深色、浅色和系统主题切换后，卡片、目录和玻璃材质会立即刷新，无需手动刷新页面。
- **快速搜索**：内置搜索框和搜索引擎切换，支持快速查找、发现或直接跳转。
- **AI 侧栏**：支持在新标签页中打开常用 AI 站点侧栏，减少频繁切换标签页。
- **书签管理**：支持拖拽排序、新建、编辑、删除、隐藏低频目录，以及配置链接打开方式。
- **个性化外观**：支持背景、模糊、透明度、主题和图标等外观设置。

## v4.0.0 更新重点

- 平铺模式升级为更明确的分屏布局：左侧目录，右侧卡片列表。
- 重构平铺模式顶部区域：时间、日期标语和搜索框在同一视觉系统中对齐。
- 优化平铺卡片网格：卡片更有呼吸感，并保留稳定的多尺寸 Bento 排列。
- 修复主题切换后卡片和目录颜色需要刷新才更新的问题。
- 降低目录编辑、删除等操作图标的默认存在感，仅在 hover 或 focus 时突出。
- 平铺卡片默认隐藏链接预览，优先展示图标和名称。

## 安装方式

### Chrome 应用商店安装

Chrome 应用商店链接待补充。

### 开发者模式安装

1. 下载并解压本项目代码。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择包含 `manifest.json` 的项目目录。
6. 打开新标签页即可使用。

## 本地开发

```bash
npm install
npm run build
```

说明：日常调试可以直接加载项目根目录。只有需要生成发布包时才需要执行构建流程。
